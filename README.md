# news-image-20261118 — The World in One Day

One image that sums up the world news of **Wednesday 18 November 2026**,
drawn as a newspaper front page: masthead with the date, six illustrated
story panels, and a source footer.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```

Pure Python 3 standard library (`zlib`, `struct`), fully deterministic —
two runs produce byte-identical output. No network, no API keys, no fonts
from disk: the 5x7 bitmap font and the PNG encoder are hand-written in
`main.py`, and every pictogram is drawn in code.

## The six stories (all verified against 2+ sources; see NOTES.md)

1. Trump in Manila for the Quad summit; Marcos talks today, then Shenzhen.
2. Ukraine cripples the Crimean Bridge; Russia hits Kyiv's bridges.
3. Iran drones target a US radar in Bahrain; intercepted, no damage.
4. Nvidia sales double to $115.8bn; board says Huang will not return.
5. UK sanctions eight Israeli settlement firms and a Gaza aid-blocking group.
6. Cyclone Akvan bears down on India; landfall due Friday, winds to 145 km/h.
